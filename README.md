# Easy-CSS
Easy CSS is a collection of nice, clean and classless CSS sheets like Black and White or Turquoise Green to instantly style standard HTML pages.



This is a **Work in Progress**. I will be adding more themes and colors over time whenever I build new ones an have enough time.

---

## Why use this?

I wanted a quick way to make basic HTML pages look decent without having to install huge frameworks or write the same styles over and over. 

These are drop-in stylesheets. You do not need to add any classes to your HTML elements. Just link the CSS file, and standard tags like `<h1>`, `<p>`, `<code>`, and `<button>` will look good instantly.

* **Zero setup:** Just plain CSS. No JavaScript, no build tools, no overhead.
* **Completely free**


---

## How to use it

1. Download the files to your project folder.
2. Link your preferred CSS file in the `<head>` of your HTML document.
